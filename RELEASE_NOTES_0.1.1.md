# Intentional Fixes v0.1.1 — Maintenance Toolkit package

This download is for the **X-Plane 737NG Maintenance Toolkit**, version
0.21.1 or newer. Select Intentional Fixes in the Zibo or LevelUp patch group.
The Toolkit applies your other functional patches first, then these fixes.

Both aircraft receive the same 14 core FMS fixes. The CPDLC correction is
applied only when CPDLC is selected; the LevelUp Weight & Balance correction
is applied only when that module is selected. See the
[fix catalog](https://github.com/wahltho/X-Plane-Zibo-LevelUp-737NG-Intentional-Fixes/blob/main/FIX_CATALOG.md)
for descriptions.

For an untouched original .35 Lua file, the separate
[v0.1.0 standalone installer](https://github.com/wahltho/X-Plane-Zibo-LevelUp-737NG-Intentional-Fixes/releases/tag/v0.1.0)
is also available. If you have already used it, uninstall with the same
installer before switching to Toolkit management.

The patch adds no FMC pages or options, leaves `zibomod.xpl` unchanged and
does not distribute a complete aircraft Lua file. Close X-Plane before
installing and keep your own aircraft backup.

Five source/package tests and the Toolkit's 546 tests passed for this release.
These checks do not establish simulator behavior.

This is an unofficial patch, not affiliated with, endorsed by or supported
by Zibo, LevelUp or Laminar Research. For support, use only the
